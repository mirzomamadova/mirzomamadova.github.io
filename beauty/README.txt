ВОЛОСЫ И МАКИЯЖ
Готовый сайт в выбранном графичном стиле.

Главная: index.html
Услуги: services.html
Работы: portfolio.html
Контакты: contacts.html

Сайт работает без сборки. Для просмотра откройте index.html.
На GitHub Pages содержимое папки размещается в beauty/.
Телефон и ссылки на запись находятся в contacts.html и подвалах страниц.
Все кнопки «Записаться» ведут в контакты.
В портфолио — 13 подготовленных фото и 3 видео с музыкой.
Исходные фотографии сохранены; маленькие WebP-копии используются для быстрой загрузки.
Шрифты Manrope и Unbounded распространяются по SIL Open Font License; лицензии приложены.
